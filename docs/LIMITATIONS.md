# System Limitations & Known Scope Constraints

1. **Local Model Hardware Dependency:** Performance and throughput of local LLM diagnosis depend heavily on local GPU/CPU hardware.
2. **External API Rate Limits:** When using real Gemini API keys, intelligence provider calls may be subject to quota limits or rate throttling.
3. **No Automatic Training:** LLMForge Lab generates and audits validated training corpora, but does not automatically trigger model fine-tuning processes (training must be initiated separately).
